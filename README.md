# Strong NT Bidding Trainer

Practice bidding drills for a 5-card majors / strong 1NT (15-17) system. You sit South and bid whole auctions. Partner is dealt a real hand and bids by the same chart. In the doubling and cue-bid drills all four hands are dealt and the opponents bid too.

There are 16 drills of 25 hands each. Each set of 25 is picked from a larger deal to cover as many different situations as possible.

## The chart

The system is the A3 flowchart in [docs/5CM_SNT_Bidding_Flowchart_A3.pdf](docs/5CM_SNT_Bidding_Flowchart_A3.pdf). It is generated by `docs/build_chart.py`: run `python3 docs/build_chart.py chart.html`, then print the HTML to PDF at A3 landscape.

Under each answer, the trainer shows which part of the chart it comes from (Chart A to H). Where the chart is silent, the trainer uses its own agreement and labels it **Trainer guide**. When you change a rule in the app, change the chart too so the two stay in step. [docs/CHART-QUESTIONS.md](docs/CHART-QUESTIONS.md) lists every trainer guide and the open questions.

## Run it

Open `index.html` in a browser. No install or build step is needed.

In VS Code, install the **Live Server** extension (by Ritwick Dey) to reload the page every time you save. Then right-click `index.html` and choose **Open with Live Server**.

## Test it

Open `tests/index.html` in a browser. The page runs every test and lists the results: green means all passed. Your real saved progress is not touched.

From a terminal (Git Bash on Windows, or Linux/macOS), run `bash tests/run.sh`. It uses Chrome, Chromium or Edge in the background and fails if any test fails. GitHub runs the same script on every push (see the **Actions** tab).

**Run the tests after every change to the chart or the drills.** They check worked examples of the chart, deal 8 rounds of every drill (both systems for the Helvic drills), and make sure every auction is legal for every seat, every answer has a rule id, and every explanation matches the hand. They end with a **rule coverage** line: the rules no drill ever asks of you.

## Put it online with GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then save.
4. After a minute the trainer is live at `https://<your-username>.github.io/<repo-name>/`.

## Where things live

| File | What it holds |
|---|---|
| `index.html` | The page. Loads the scripts below, in this order. |
| `js/cards.js` | Building blocks: suits, calls, `R` / `amb` / `gap`, HCP, balanced shapes, losing trick count, the seeded random numbers and dealing. |
| `js/rules.js` | The uncontested chart, one function per decision: openings, responses to 1NT/1M/1m, opener's rebid and responder's next call, 2NT/2♣/weak twos/pre-empts, slam tools and LTC. |
| `js/competitive.js` | The competitive chart (F and H): overcalls, doubles, Cappelletti, the cue bid after a takeout double, penalty doubles and reopening, our 1NT doubled (chart or Helvic), the unassuming cue bid, support doubles. |
| `js/auction.js` | Keeps the whole auction, all four seats (`auctionState`), picks which rule applies at each point (`chartCall`, `sysCall`), plays a whole auction (`simulate`, opponents pass) and a scripted four-hand one (`sim4`, opponents bid). |
| `js/drills.js` | The uncontested drills, the LTC drill, Mixed, and `buildSet`, which deals each set of 25. |
| `js/contested.js` | The four-hand drills: the opponents' scripts and the recipes for penalty doubles, their 1NT, our 1NT doubled, the unassuming cue bid and support doubles. |
| `js/app.js` | The page itself: home screen, Chart/Helvic switch, bidding box, number pad, feedback, results and saved progress. |
| `style.css` | Colours (light and dark), type and layout. |
| `tests/` | The tests (see above). |
| `docs/` | The chart, how the code works, open questions about the chart, and ideas for what to build next. |

Each answer's explanation is written next to its rule, as the second argument of `R(bid, why, ruleId)`. The rule id starts with the chart letter: `'A.stayman'` is the Stayman rule in chart A.

More detail: [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) explains the code and walks through changing a rule or adding a drill. [docs/ROADMAP.md](docs/ROADMAP.md) has ideas for the future. [CHANGELOG.md](CHANGELOG.md) records what has changed.

## How the trainer reads the chart

- A hand is only dealt if your **first** call is unambiguous. Later in the auction, if the chart allows more than one call (or gives none), the auction stops there and the drill says why. Trainer guides fill the commonest gaps, so most auctions now reach a contract.
- Bidding is by the chart's point ranges. The one place the chart says to use the losing trick count, opener with 13-14 after a limit raise, uses it; the LTC drill practises counting.
- Slam: once a fit is found, 31+ between you (your points plus partner's shown minimum) asks with 4NT, but only holding 2+ key cards; otherwise bid game. An unclear reply is read low. 5NT asks for kings only when the asker knows the side holds the trump queen, so a king shown leads to the grand.
- Slam hands are only dealt in the Slam and Mixed drills. The other drills skip hands with 31+ between you, so they stay about game decisions.
- **Our 1NT doubled**: choose the chart system or Helvic Wriggle with the switch on the home screen. Each keeps its own progress.
- Only your first attempt at a hand is scored. Bidding a played hand again (from the progress dots) is practice.

Progress is saved in the browser (localStorage), so each person keeps their own scores. If the drills change so that a set deals different hands, that set's unfinished progress is reset; best scores are kept. Every device deals the same hands for the same set.
